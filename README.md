# Проект : Написание простого веб-приложения без применения фреймворков

## О проекте
Данный проект представляет собой простое веб-приложение, построенное без использования веб-фреймворков. Основная цель — понять работу HTTP-запросов и научиться создавать сервер на Python с обработкой GET и POST запросов.

## Задачи проекта
Создать прототипы страниц с помощью Bootstrap. Результатом являются HTML-документы с подключенными Bootstrap-стилями.
Реализовать веб-сервер, который на любой GET-запрос возвращает страницу «Контакты». Для корректной работы файлы подключены с удаленного репозитория.
Обработать POST-запросы: принимать данные от пользователя и выводить их в консоль.
Структура проекта
```
/src
  ├── contacts.html
  ├── main_page.html
  ├── catalogue.html
  └── categories.html
app.py
README.md
```
* Папка src содержит HTML-шаблоны.
* app.py — основной файл приложения, запускающий сервер и обрабатывающий запросы.

## Как запустить проект
1. Убедитесь, что у вас установлен Python 3.12.
2. Склонируйте репозиторий или скачайте файлы проекта.
3. Перейдите в папку с проектом в терминале.
4. Запустите сервер командой:
```python app.py```
5. Откройте браузер и перейдите по адресу:
```http://localhost:8000```
6. Сервер будет обрабатывать GET-запросы и возвращать страницу «Контакты».
7. Для отправки POST-запроса используйте форму на странице (если есть) — данные будут выведены в консоль сервера.

## Описание кода
* Класс MyServer наследуется от BaseHTTPRequestHandler.
* Метод do_GET отвечает за обработку GET-запросов и отправку HTML-страницы.
* Метод do_POST принимает данные из формы и выводит их в консоль.
* Функция run() запускает HTTP-сервер на локальном хосте и порте 8000.

## Используемые технологии
- Python (модуль http.server)
- HTML, CSS
- Bootstrap (подключен через CDN)
